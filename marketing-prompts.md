# Prompts Marketing — Cohesif Energy

> Répète si le rendu ne te convient pas : ajoute *"même style, version portrait/paysage"* pour adapter au format.

In the foreground bottom-right corner, place the Cohesif Energy logo (uploaded reference image) on a semi-transparent dark card, clean white padding, no shadow clipping.

No extra text, no watermarks.

## Conseils pour de meilleurs résultats

| Astuce | Détail |
|---|---|
| **Upload le logo** | Glisse `logo.png` dans la conversation ChatGPT avant de coller le prompt |
| **Ratio** | Demande `"1:1"` pour Instagram carré, `"9:16"` pour Story/Reels, `"16:9"` pour Facebook/bannière web |
| **Itération** | Si le texte est mal rendu, ajoute : *"remove all text from the image"* puis rajoute le texte toi-même sur Canva |
| **Couleurs exactes** | Si les couleurs dévient, précise : *"brand green hex #0f7c4a, brand blue hex #0f4c81, no other colors"* |
| **Version FR/EN** | Pour un rendu plus propre, ChatGPT génère mieux l'anglais — le texte final peut être retouché sur Canva |
